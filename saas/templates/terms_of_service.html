3. Repository Scanning and Analysis

3.1 How Scanning Works

GVD uses the following process to scan repositories:

  1. Repository is cloned to a temporary local directory
  2. Local clone is analyzed for security vulnerabilities
  3. Security report is generated from the analysis
  4. Temporary repository clone is permanently deleted
  5. Report is displayed and available for download

3.2 What Gets Analyzed

GVD analyzes repositories for:

  • Exposed secrets and credentials (API keys, tokens, passwords)
  • Sensitive files and configurations
  • Git history for exposed secrets
  • Common security patterns and risks

3.3 What Does NOT Get Stored

GVD does NOT permanently store:

  • Your repository source code
  • Repository file contents
  • Full git history
  • Permanent scan history or records

Only security reports are generated and stored temporarily in your session.
